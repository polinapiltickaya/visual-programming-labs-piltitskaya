## Эндпоинты

### 1. GET /api/text
Возвращает простой текст.
* **Успех (200 OK):** `text/plain`
* **Пример ответа:** `Привет, это простой текст от Node-RED!`

### 2. GET /api/info
Возвращает JSON с информацией.
* **Успех (200 OK):** `application/json`
* **Пример ответа:**
  ```json
  {
    "student": "Пильтицкая Полина",
    "group": "СДП-ИИ-241"
  }
