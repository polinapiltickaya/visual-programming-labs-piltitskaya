## 1. Описание базового приложения
Разработано мобильное приложение «Приветствие» (`lab6-piltitskaya-sdp-ii-241`) на low-code платформе Kodular. 

На главном экране `Screen1` размещены следующие визуальные компоненты:
* `Label` (`lbl_piltitskaya_surname`) — обязательный идентификатор автора на английском языке (`Piltitskaya`), отображаемый на экране при запуске;
* `Label` (`lbl_piltitskaya_title`) — заголовок с текстом «Введите имя»;
* `TextBox` (`txt_piltitskaya_name`) — поле для ввода имени с подсказкой (`Hint`) «Ваше имя»;
* `Button` (`btn_piltitskaya_greet`) — кнопка запуска логики с текстом «Поздороваться»;
* `Label` (`lbl_piltitskaya_result`) — поле для вывода итогового сообщения.

**Логика работы:**  
При нажатии на кнопку «Поздороваться» (`Click`) срабатывает условный оператор `if / then / else`, который проверяет содержимое текстового поля на пустоту с помощью блока `is empty`. Если пользователь не ввёл имя, в нижний `Label` выводится предупреждение «Введите имя!». В противном случае с помощью блока соединения строк `join` формируется персональное приветствие «Привет, `<Имя>`!».

## 3. Освоенные компоненты и блоки
* **Визуальные компоненты:** `Label`, `TextBox`, `Button`.
* **Блоки управления и событий:** обработчик нажатия кнопки (`when ...Click do`), условное ветвление (`if / then / else`).
* **Блоки работы со строками:** проверка пустоты строки (`is empty`), конкатенация строк (`join`), текстовые литералы (`" "`).

## 5. Ограничения бесплатного тарифа Kodular
При работе в среде Kodular Creator на бесплатном тарифе (Free Plan) учитывались следующие ограничения платформы:
* **Количество проектов:** не более 10 проектов в рамках одного аккаунта;
* **Объём ассетов:** общий размер загружаемых медиафайлов ограничен 10 МБ на проект;
