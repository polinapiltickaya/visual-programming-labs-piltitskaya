**Название процесса:** Заказ еды в ресторане с доставкой.

**Участники (роли):** Клиент, Система заказа, Ресторан (Администратор/Кухня), Служба доставки (Курьер).

**Описание процесса:**
1. Клиент открывает мобильное приложение ресторана и выбирает блюда из меню.
2. Клиент переходит в корзину и указывает адрес доставки.
3. Система проверяет корректность введенного адреса и доступность зоны доставки.
4. Клиент выбирает способ оплаты (онлайн-оплата картой или наличными курьеру).
5. Если выбрана онлайн-оплата, система проводит транзакцию через платежный шлюз.
6. После успешной оплаты система отправляет уведомление о новом заказе администратору ресторана.
7. Администратор подтверждает заказ и передает его на кухню для приготовления.
8. Параллельно с приготовлением блюд на кухне система автоматически ищет свободного курьера поблизости.
9. Как только заказ упакован, а курьер прибыл в ресторан, курьер забирает заказ.
10. Курьер доставляет еду по указанному адресу и передает ее клиенту.
11. Клиент получает заказ и подтверждает его получение в приложении, после чего процесс завершается.
