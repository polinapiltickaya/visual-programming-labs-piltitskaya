## Ход выполнения работы

### Часть 2. Базовые workflow в n8n
1. **`flow-01-manual-set`**: Настроен ручной запуск триггера и базовая установка параметров с фиксацией фамилии.
2. **`flow-02-code`**: Реализована генерация массивов данных с помощью JavaScript, использование циклов (`for`) и условных операторов (`if/else`).
3. **`flow-03-if`**: Настроено ветвление потока данных на основе числового сравнения значений.
4. **`flow-04-set`**: Сформирован комплексный объект сообщения, содержащий системные параметры (`topic`, `timestamp` в формате ISO) и полезную нагрузку (`payload`).
5. **`flow-05-http`**: Выполнен успешный GET-запрос к публичному API (Chuck Norris Jokes) с дальнейшей модификацией и обогащением полученного JSON-ответа в ноде `Code`.
6. **`flow-06-schedule`**: Настроен триггер регулярного автоматического запуска по расписанию (интервал в 1 минуту) с генерацией меток времени.

### Часть 3. Интеграция с Redis
1. В Docker-контейнере запущен экземпляр Redis (`redis:7`).
2. В n8n настроено подключение (`Credentials`) с использованием хоста `host.docker.internal` и порта `6379`.
3. Созданы и верифицированы два сценария:
   * Запись и чтение индивидуального ключа `piltitskaya` (`flow-09-redis.json`).
   * Удаление ключа и программная проверка его отсутствия в базе данных (`flow-10-redis.json`).
