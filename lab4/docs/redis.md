# Отчет по интеграции с Redis (Часть 3)

В рамках данной части лабораторной работы выполнялось взаимодействие визуальных потоков n8n с NoSQL-базой данных Redis, развернутой в Docker-контейнере.

## Среда и параметры подключения
- **СУБД:** Redis (версия 7, запущена через Docker)
- **Хост:** `host.docker.internal`
- **Порт:** `6379`
- **Имя ключа (индивидуальное):** `piltitskaya`

---

## Реализованные workflow

### 1. Создание и чтение ключа (`flow-09-redis.json`)
Поток предназначен для проверки записи и чтения данных из Redis:
* **Manual Trigger:** Инициация запуска вручную.
* **Redis (Set):** Записывает по ключу `piltitskaya` строковое значение с текстом приветствия и указанием автора.
* **Redis (Get):** Сразу после записи считывает значение по тому же ключу для подтверждения успешности операции.

### 2. Удаление и проверка отсутствия ключа (`flow-10-redis.json`)
Поток проверяет механизм очистки данных:
* **Manual Trigger:** Запуск сценария.
* **Redis (Delete):** Удаляет ключ `piltitskaya` из хранилища Redis.
* **Redis (Get):** Пытается запросить удаленный ключ (возвращает `null`).
* **Code:** Проверяет полученный результат. Если ключ всё ещё существует, выбрасывает ошибку; в противном случае формирует подтверждение об успешном удалении (`exists: false, deleted: true`).

## Результаты
Все операции завершились успешно, целостность данных подтверждена через визуальные интерфейсы n8n и логи выполнения.
