## 1. Цель работы
Освоить no-code платформу Bubble: сгенерировать каркас веб-приложения с помощью AI, вручную доработать UI/UX (переменные, стили, UI-компоненты), спроектировать структуру базы данных (Data Type) и реализовать CRUD-логику с помощью workflows.

## 5. Часть 4. Data и Workflows

### 4.1. Структура данных (Data Type: `Trip`)
Промпт для генерации полей: `Создай структуру сущности Trip для приложения путешествий с полями названия, страны, дат, заметок, статуса и владельца`.

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `title` | `text` | Название поездки |
| `country` | `text` | Страна назначения |
| `start_date` | `date` | Дата начала |
| `end_date` | `date` | Дата окончания |
| `notes` | `text` | Заметки/впечатления |
| `status` | `Option Set / text` | Статус (Планирую / Посетил) |
| `owner` | `User` | Владелец записи |

**Скриншоты:**
* `../screenshots/06-data-type.png` — Поля типа данных `Trip`
* `../screenshots/07-data-records.jpeg` — Записи в `App Data`

### 4.2. Workflows (CRUD)
* **Create & Update:** Workflow `Trip Save Button is clicked` — создание новой записи или обновление существующей.
* **Read:** Отображение поездок в Repeating Group с динамической фильтрацией.
* **Delete:** Workflow `Del Confirm Button is clicked` — удаление выбранной поездки.

**Скриншоты:**
* `../screenshots/08-workflow-create.jpeg` — Workflow создания/изменения
* `../screenshots/09-workflow-delete.jpeg` — Workflow удаления
